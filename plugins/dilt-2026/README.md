# DiLT 2026 plugin

DiLT's extension layer on top of the AMEV vocabulary: supplemental keys, and the Keys-Combinations
that occur together in practice. The name template comes from AMEV 2026, so the manifest requires `amev-2026`.

## Contents

| File | What |
|---|---|
| `keys.json` | Supplemental key-library entries, `source: "dilt"` |
| `combinations.csv` | 1,927 rows of typical segment combinations, with the BACnet object type and unit each implies |
